# DigiBot101

A special AI assistant with voice capabilities specifically designed for personal assistant tasks and DigiMark101 digital marketing agency management.

## 🚀 Features

- **Dual Personas**: 
  - **Ava Skye** - Professional digital marketing specialist and personal assistant
  - **Matt Payne** - Technical consultant and business strategist

- **Voice Capabilities**:
  - Speech-to-text input
  - Text-to-speech output with persona-specific voices
  - Natural voice interactions

- **Deployment Options**:
  - 🌐 **Web App** - Deploy to Vercel for online access
  - 🖥️ **Desktop Widget** - Floating widget for Windows 11

- **Modern Interface**:
  - Glass-morphism design
  - Responsive layout
  - Real-time chat with typing indicators
  - Smooth animations and transitions

## 🚀 Quick Start

### Web Deployment (Vercel)
1. This repository is ready for Vercel deployment
2. Connect your GitHub to Vercel
3. Import this repository and deploy

### Desktop Widget (Windows 11)
```bash
# Clone the repository
git clone https://github.com/ShawnCooper101/DigiBot101.git
cd DigiBot101

# Install dependencies
npm install

# Run in development mode
npm run electron

# Build for production
npm run dist
```

## 📖 Usage

1. **Choose Your Assistant**: Select between Ava Skye or Matt Payne
2. **Voice or Text**: Type your message or click the microphone for voice input
3. **Get Help**: Ask about marketing, business strategy, scheduling, or technical solutions

### Example Interactions

**Marketing with Ava:**
- "Help me create a social media strategy"
- "What's the best time to post content?"
- "Schedule a team meeting"

**Technical with Matt:**
- "Optimize our website performance"
- "Analyze our data metrics"
- "Implement automation tools"

## 🛠️ Technology Stack

- **Frontend**: Next.js 15, React, TypeScript
- **Styling**: Tailwind CSS with custom animations
- **Voice**: Web Speech API (SpeechSynthesis & SpeechRecognition)
- **Desktop**: Electron for cross-platform desktop app
- **Deployment**: Vercel for web, Electron Builder for desktop

## 📱 Desktop Widget Features

- **Always on Top**: Floating widget that stays visible
- **Draggable**: Position anywhere on your screen
- **Resizable**: Compact widget or full window mode
- **System Tray**: Minimize to tray when not needed
- **Native Integration**: Windows 11 optimized
